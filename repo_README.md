# 💧 Aakurru Water

**Clean, solar-powered drinking water for the Lama Lama community at Port Stewart, Cape York.**

A design proposal prepared for the **EWB Challenge 2024** by students of *31265 Communication for IT Professionals* at the University of Technology Sydney.

🌐 **Live website:** [https://aakurru-water.github.io](https://aakurru-water.github.io) *(replace with your actual GitHub Pages URL after deploy)*

## 📋 Project Summary

| | |
|---|---|
| **Design Area** | Design Area 6 — Water Resilience |
| **Project Opportunity** | Safe drinking water for Port Stewart |
| **Community Partner** | Yintjingga Aboriginal Corporation (YAC) |
| **System Cost** | AUD $3,750 per module |
| **Serves** | 25–30 people per module |
| **Power Source** | 100% solar, off-grid |

The project addresses the long-standing lack of safe drinking water at Port Stewart through a low-cost, low-maintenance system combining wet-season rainwater harvesting, three-stage filtration, a solar-powered pump, and sealed storage. The design is intended to be installed, operated, and maintained by community members.

## 🛠️ How to Edit

### For team members (web-based, no installation needed)

1. Navigate to `index.html` in this repo
